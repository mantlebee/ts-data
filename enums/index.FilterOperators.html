    Enumeration FilterOperators

    Comparison applied by a Filter. The values follow OData 4 where OData defines them, otherwise the most common naming (Strapi, Prisma, PrimeVue). The operator decides the shape of the value of a Filter: a list for FilterOperators.in and FilterOperators.notIn, a Range for FilterOperators.range, a single value otherwise.
