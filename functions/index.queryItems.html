    Function queryItems

    • queryItems<TItem = any>(
          items: List<TItem>,
          payload: QueryItemsPayload<TItem>,
          options?: InMemoryQueryItemsReaderOptions<TItem>,
      ): List<TItem>

      Resolves a payload against a list, as a server would, delegating each step to the in-memory utils of the feature: filterItems with payload.filters, sortItems with payload.sorts, projectItems with payload.projections, distinctItems when payload.distinct, then pageItems with payload.pagination. The list and its items are never mutated; the result is always a new array.

      Type Parameters

      • TItem = any

      Parameters

      • items: List<TItem>

        Items to query.

      • payload: QueryItemsPayload<TItem>

        Query to resolve; every property is optional.

      • Optionaloptions: InMemoryQueryItemsReaderOptions<TItem>

        Comparison options, see InMemoryQueryItemsReaderOptions.

      Returns List<TItem>

      the items of the requested page, every matching item when the payload has no pagination, a copy of the list when it has no property.

      Example

      const page = queryItems(users, {
        filters: { filters: [{ field: "age", operator: FilterOperators.greaterThanOrEqual, value: 18 }], logic: FilterLogics.and },
        pagination: { itemsPerPage: 20, page: 2, totalItemsCount: 0 },
        sorts: [{ asc: true, field: "lastName" }],
      });
