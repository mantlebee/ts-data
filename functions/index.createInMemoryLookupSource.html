      A lookup source over a list, through the in-memory reader of query-items: the same semantics as createLookupSource, so a list in a story or a spec behaves like a server. search compares the text the way the in-memory filters do (case-insensitive unless caseSensitive).

      Type Parameters

      • TItem

        Type of the items, inferred from the list.

      • TValueField extends string = KeyOf<TItem>

        Field holding the key, inferred from the options.

      Parameters

      • items: List<TItem> | (() => List<TItem>)

        The list, or a function returning the current list, called on every call.

      • options: LookupReaderOptions<TItem, TValueField> & InMemoryQueryItemsReaderOptions<TItem>

        The fields of the text and of the key, plus the comparison options of the in-memory reader.

      Returns ILookupSource<TItem, TItem[TValueField]>

      a stateless source over the list.

      Example

      const departments = createInMemoryLookupSource(Departments, { textField: "name", valueField: "id" });
