    OptionalcaseSensitive

    caseSensitive?: boolean

    true to compare strings as they are. By default (false) strings are lower-cased before any comparison, so equal, contains, startsWith, endsWith, in and the sorts ignore the case. equalInsensitive ignores the case whatever this option.

    OptionaltoComparable

    toComparable?: InMemoryQueryItemsComparer<TItem>

    Replaces the default conversion (toComparableValue) of a value into the primitive actually compared. It receives both sides of every comparison, the value of the item and the value of the filter, with the field they belong to, so the rule can differ per field. Its result is used as it is: lower-case the strings yourself when needed. Return null for an unset value.

    Example

    // Prices are value objects compared by their amount in cents.
    const options: InMemoryQueryItemsReaderOptions<Product> = {
      toComparable: (value, field) =>
        field === "price" ? (value as Price).cents : toComparableValue(value),
    };
